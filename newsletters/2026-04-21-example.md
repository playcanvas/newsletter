# April at PlayCanvas

Welcome to the first edition of the PlayCanvas newsletter. Every month we round up the biggest changes in the engine, a few community projects worth your time, and a tip or two to help you ship faster.

## Engine release

We shipped a new version of the PlayCanvas engine this month with highlights including:

- Faster shader compilation on WebGPU
- Improved Gaussian Splatting renderer with better sorting performance
- A new `PointLight.shadowType` API for per-light cascaded shadow control

Read the full release notes on [GitHub](https://github.com/playcanvas/engine/releases).

## Tip of the month

When authoring email, use animated GIFs for motion - HTML5 `<video>` tags are stripped by most email clients.

> If you need a real video, use a static poster image that links to your hosted video on YouTube or elsewhere.
